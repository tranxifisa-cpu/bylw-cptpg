# Research Figure Rules

For every new or revised figure intended for a scientific paper, follow both installed skills' applicable workflow and checks:

- `academic-figure-skill` governs the scientific question, figure plan, data integrity, journal specifications, and its required quality checks.
- `scientific-figure-making` from `figures4papers` governs Matplotlib implementation patterns, examples, and publication styling where compatible with the first skill's required baseline.

Read the required and relevant skill references before creating or revising a paper figure. For a new figure, follow the academic skill's question, data, and panel-planning steps before rendering. Preserve the source data and analysis logic. Include the academic skill's required style and export baselines and do not use default palettes that either skill rejects. If a figure-specific requirement or the two skills' explicit rules cannot be reconciled, identify the conflict before changing the figure and follow the user's stated journal requirements.

Use `figure-spec` for architecture and workflow diagrams, and `paper-illustration` for qualitative illustrations. Use Tavotto only when the user explicitly requests interactive editing of an existing figure, keeping the figure's established scientific style.
